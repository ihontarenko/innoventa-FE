The Gazette of Counting Things

A host page with loud opinions about typography, so an embed that leaks is obvious immediately.

Before the embed

This paragraph is serif, 19px, brown, on a striped background. If any of that changes after the iframe loads, the embed is leaking styles into its host — which is the one thing it must never do.

The embed

After the embed

Still serif, still 19px, still brown. The iframe is a document boundary, so this is expected rather than impressive — the test is that nothing here had to be defended.

Open with ?theme=dracula or &scale=1.25 on the iframe src to check those too.
